# Triage labels

工程技能使用下列角色對應實際 GitHub 標籤。提到角色時，使用 tracker 欄位的完整字串。

| 技能角色 | Tracker 標籤 | 意義 |
| --- | --- | --- |
| needs-triage | needs-triage | 維護者需要評估 |
| needs-info | needs-info | 等待回報者提供資訊 |
| ready-for-agent | ready-for-agent | 規格完整，可交由 agent；仍須遵守 blocker |
| ready-for-human | ready-for-human | 需要人工實作 |
| wontfix | wontfix | 不予處理 |

調整既有標籤詞彙時修改本表的 tracker 欄位，避免為同一角色建立重複標籤。
